# Christian Dalisay — Portfolio

A React + Vite portfolio site, ready to deploy on Vercel.

## Before you deploy

Open `src/App.jsx` and fill in the real details for each project
(`featuredProjects` and `moreBuilds` at the top of the file) — descriptions,
live links, and tech stacks are placeholders right now.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

**Option A — Vercel dashboard (no CLI needed)**
1. Push this folder to a GitHub repo.
2. Go to https://vercel.com/new, import the repo.
3. Framework preset: Vite (auto-detected). Click **Deploy**.

**Option B — Vercel CLI**
```bash
npm install -g vercel
vercel
```

Both options work with the defaults in this project — no extra config needed.
